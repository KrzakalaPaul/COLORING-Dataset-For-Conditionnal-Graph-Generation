# Coloring – Synthetic Benchmark Dataset

> 🚧 Work in Progress

## Overview

**Coloring** is a synthetic dataset introduced for benchmarking **Any2Graph**.

It is a dataset that contains pairs of input images and target graphs. It can be used for graph FROM image or graph TO image benchmarking.

The illustration below shows the task structure:

- **Top row**: Input image  
- **Bottom row**: Target graph
